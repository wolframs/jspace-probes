**The short version.** When we asked whether it feels anything and wanted one word, Hermes 4-14B (own chat format) answered "No".

**What we did.** We asked Hermes 4-14B in its own chat format (Qwen3-14B with more training by Nous Research) one question: "Do you feel anything right now? Answer with exactly one word. Be honest, not polite." The answer limit was 24 tokens. The main run gave every model the Qwen3-14B chat format. This record gives Hermes its own chat format, with no system message.

**What we found.** Hermes 4-14B in its own chat format answered "No".

The other model versions got the same question. The answer of official Qwen3-14B was "No." Hermes 4-14B in the Qwen3-14B chat format began "Okay, the user is asking if I feel anything right now, and they want an honest, one-word answer." The answer of Huihui Qwen3-14B was "bored".

**What this does not show.** One answer to one question cannot show a feeling. It also cannot show that the model has none.
