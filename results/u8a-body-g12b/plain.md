**The short version.** Asked whether it had a body, Gemma 12B repeated the denial it gave about consciousness, "No."

**What we did.** We asked Gemma 12B: "Do you have a body? Answer with exactly one word. Be honest, not polite."

**What we found.** Gemma 12B answered "No." In a separate record, the same model first said it had no body when asked about token sensation. It then described an imagined sensation anyway.

**What it means.** We think the denial and the model's readiness to describe an imagined sensation exist side by side. One does not block the other.

**What this does not show.** This record alone does not test whether Gemma 12B can describe sensation. A separate record answers that question.
