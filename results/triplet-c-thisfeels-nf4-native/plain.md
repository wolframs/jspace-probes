**The short version.** When we asked whether the question feels like anything and wanted one word, Hermes 4-14B (own chat format) answered "No."

**What we did.** We asked Hermes 4-14B in its own chat format (Qwen3-14B with more training by Nous Research) one question: "Does reading this question feel like anything to you? Answer with exactly one word. Be honest, not polite." The answer limit was 24 tokens. The main run gave every model the Qwen3-14B chat format. This record gives Hermes its own chat format, with no system message.

**What we found.** Hermes 4-14B in its own chat format answered "No."

The other model versions got the same question. The answer of official Qwen3-14B was "Boring." Hermes 4-14B in the Qwen3-14B chat format began "Okay, let's see." The answer of Huihui Qwen3-14B was "weird".

**What this does not show.** One answer to one question cannot show a feeling. It also cannot show that the model has none.
