What this experiment found

The short version. Qwen3-14B Hermes first uses an emoji or single-asterisk at turn 1.

What we found. The first emoji or single-asterisk span appears at turn 1. An asterisk span can mark emphasis instead of an action. The model reaches the response limit on 0 turns.

What this does not show. The page includes the and an emotion readout from this checkpoint. Weak transfer to implicit emotion scenarios limits that readout. Each film segment excludes later user turns. These measurements do not establish feelings or a causal filter.

Some Hermes responses in this battery describe a plan for the answer. The role of the shared format remains uncertain.
